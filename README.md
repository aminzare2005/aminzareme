# Amin Zare Portfolio

Welcome to the personal portfolio website of Amin Zare (@cwpslxck), a digital creator and frontend developer.

---

## Overview

This is a modern, interactive portfolio website showcasing Amin's work as a frontend developer, product manager, and creative professional. The site features a comprehensive presentation of projects, professional experience, and a comprehensive network of professional and social connections.

The portfolio is built with a focus on **modern web development practices**, **performance optimization**, and **user experience**. Every detail has been crafted to present Amin's work in the most professional and engaging way possible.

---

## Key Features

### Interactive Portfolio

- Dynamic project showcase with detailed implementations
- Filterable categories and comprehensive project descriptions
- Live previews and direct links to source code

### Professional Timeline

- Interactive career history with timeline visualization
- Education background and skill development journey
- Responsive timeline that works on all devices

### Design Gallery

- Visual showcase of design work and creative projects
- High-quality image galleries with filtering
- Detailed case studies and design process documentation

### Social Integration

- Unified footer navigation to all social platforms
- Click-to-visit links for GitHub, LinkedIn, Instagram, X/Twitter
- Design gallery for visual content sharing

### Technical Excellence

- Built with Next.js 15 (React 19) for optimal performance
- Tailwind CSS with DaisyUI for modern styling
- Lenis library for native smooth scrolling experience
- Vercel Analytics for performance monitoring

### Cross-Platform Compatibility

- Fully responsive design that works on desktop, tablet, and mobile
- Progressive Web App capabilities
- Optimized for all major browsers

## Technical Architecture

### Stack

- **Framework**: Next.js (React 19)
- **Styling**: Tailwind CSS + DaisyUI components
- **Animations**: Lenis smooth scrolling library
- **Icons**: Lucide React + React Icons
- **Analytics**: Vercel Analytics
- **Build Tools**: TypeScript, PostCSS, ESLint

### Directory Structure

```
app/
├── layout.tsx              # Root layout with SEO and structured data
├── page.tsx                # Main portfolio page
├── (main)/                 # Main section routes
│   └── page.tsx           # Home page with hero and sections
├── (links)/                # External profile redirect pages
│   ├── github/page.tsx    # GitHub redirect
│   ├── linkedin/page.tsx  # LinkedIn redirect
│   └── ...               # Other social redirects
├── design/                 # Design gallery page
├── projects/               # Projects showcase page
└── Components/             # Reusable UI components
    ├── sections/          # Portfolio section components
    │   ├── hero.tsx       # Hero section with profile
    │   ├── work.tsx       # Projects showcase
    │   ├── timeline.tsx   # Experience timeline
    │   └── ...           # Other sections
    ├── footer.tsx         # Navigation footer
    └── ui/                # UI component library
lib/                       # Helper libraries and utilities
constants/                 # App constants and configuration
```

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
https://github.com/aminzare2005/aminzare.me

# Install dependencies
npm install
# or
yarn install
```

### Development

```bash
# Start the development server
npm run dev
# or
yarn dev

# Access at http://localhost:3000
```

### Production Build

```bash
# Build for production
npm run build
# or
yarn build
```

### Production Deployment

```bash
# Start the production server
npm start
# or
yarn start
```
